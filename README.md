# IELTS Mock Test Score Calculator

## 一、项目简介

本项目是一个使用 Python 编写的**雅思模考成绩分析器**，旨在帮助正在备考雅思的学生快速整理和比较模考成绩。

用户可以输入模考日期，以及听力、阅读、写作和口语四科成绩。程序会计算四科平均分，并将结果处理为以0.5分为间隔的雅思总分。用户还可以手动输入上一次模考的总分，查看本次成绩是提高、下降还是保持不变。

## 二、文件说明

* `IELTS Mock Test Score Calculator.ipynb`：主要程序，负责录入日期和四科成绩、计算总分、比较前后两次模考成绩。
* `README.md`：项目说明文件，介绍程序功能、使用方法、核心代码以及学习心得。

## 三、核心代码说明

### 1. 输入四科成绩

```python
listening = float(input("请输入听力成绩："))
reading = float(input("请输入阅读成绩："))
writing = float(input("请输入写作成绩："))
speaking = float(input("请输入口语成绩："))
```

`input()` 用于接收用户输入，`float()` 将输入内容转换为可参与计算的数字。

### 2. 计算雅思总分

```python
average = (listening + reading + writing + speaking) / 4
overall = int(average * 2 + 0.5) / 2
```

第一行计算四科平均分；第二行按照雅思总分计算规则，将平均分处理为以0.5为间隔的总分。例如四科为 `6.0`、`7.0`、`6.5`、`6.5` 时，最终总分为 `6.5`。

### 3. 比较两次模考成绩

```python
last_score = input("\n请输入上次模考总分（首次可直接回车）：")

if last_score != "":
    change = overall - float(last_score)

    if change > 0:
        print("成绩提高啦！")
    elif change < 0:
        print("成绩下降咯，继续努力~")
    else:
        print("成绩与上次持平呢")
```

如果用户输入了上次总分（即不为回车），程序就计算两次成绩的差值，并通过 `if`、`elif` 和 `else` 判断成绩变化情况。
